How to Add Widgets to Vivaldi

1

Copy the Widget URL

On any card in this Showroom, click the COPY VIVALDI URL button. It copies the exact local file:/// path to your clipboard.

2

Open Vivaldi Start Page

Open a New Tab in Vivaldi, click Add Widget (or right-click the Start Page) and select Webpage.

3

Paste & Configure

Paste the copied file:///... URL into the address input. Uncheck "Share Theme Colors" so the widget displays its authentic custom typography and textures.

4

Recommended: Clean CSS Mod

Apply our bundled CSS in vivaldi-css/ to remove default white card backgrounds and title bars while keeping hover access to the 3-dots menu.
